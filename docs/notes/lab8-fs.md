# lab8 file system

这次关心：磁盘（数据持久化、怎么存大文件、链接）

文件系统：把用户看到的文件和磁盘上的字节对应起来的那套机制

## Large files

适配二级间接块


文件在磁盘上有两类结构：

- inode: 元信息卡片，记录大小、文件内容散落在哪些块，是一张清单，inode本身也在磁盘上，有专门的inode区域
- 数据块：散落在磁盘各处的内容块

inode里的addrs[]数组存一串块号，这一串块连起来就是文件

0-11块是直接块

12块是间接块，指向一个索引块，这里面装了256个块号

索引块就混在普通数据区里，就读的时候不一样

在这个基础上，再适配二级间接块，就实现大文件了


## Symbolic links

链接

硬链接就是同一个文件的另一个名字，存的是inode，inode必须真实存在

符号链接就是一块指路牌，存的是字符串，创建符号链接时不检查目标是否存在
