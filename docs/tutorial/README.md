# tutorial 目录说明

xv6-labs-2025 的**学习教程文档**。定位是"把每个 lab 讲懂"，不是交作业的报告——
交作业的报告在 `docs/reports_simple/`，这里只做学习讲解。

## 定位

这是一套"讲解式"教程，读法像教材：每个 lab 先讲清前置知识，再讲"代码该怎么改"，
最后对着仓库里的**真实代码**逐行讲"为什么这么写"，并用自检问题检验自己是不是真懂了。

## 目录结构

```text
tutorial/
  README.md               本文件
  labs/
    00-xv6-overview.md    前置导览：代码地图 + C 项目组织 + 各 lab 前置知识
    lab1-util.md          Lab1 Utilities 讲解：用户程序如何变成命令 + 逐任务代码讲解
    lab3-pgtbl.md         Lab3 Page Tables（进行中）
    ...
  assets/
    pgtbl/                讲解中引用的截图素材（grade.png、pgtbltest.png）
    ...
```

## 写作约定

- 主线三步：**先讲清前置知识 → 再讲代码该怎么改 → 逐行细致讲为什么这么写**。
- 讲解要对着仓库里的**真实代码**，带文件路径、函数名，不泛泛而谈。
- 多用类比和自检问题；自检问题放每节末尾，答案能在正文找到。
- **不套**"实验目的 / 实验步骤 / 遇到的问题 / 心得"的报告四小节格式——那是给
  `docs/reports_simple/` 用的。

## 一条最重要的原则

> 每一段讲解，都应该是你能脱离笔记、向别人解释清楚的话。
> 写到卡住、只能照抄代码却说不清为什么，就说明那里还没真懂——回去看代码，弄懂了再写。

教程是"你已经懂了"的**记录**，不是"显得懂了"的装饰。
